# VideoProxy Insights

Reports and interactive tools for understanding data, rollouts, and training outputs.

## Contents

- `event_logic_ablations/`: batch analysis for event-logic rollout ratios.
- `hier_seg_frame_budget/`: batch frame-budget analysis for hierarchical segmentation.
- `rollout_viewer/`: browser UI for rollout JSONL inspection.
- `data_browser/`: browser UI for browsing data samples and media.

Use `insights/` when the work reads existing artifacts and produces reports or
interactive views. Use `experiments/` when launching training.
